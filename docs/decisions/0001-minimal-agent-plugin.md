# 0001 · 收缩成最小 agent 插件

日期：2026-10-07　状态：生效　取代：此前全部 ADR（0001–0009，见 git 历史）

## 背景

这个项目先后做过两轮扩张：M1–M8 全管线（分析器、素材阶段、校验阶段、HTML 视图、
配音、渲染、四套风格预设 × 31 token、多 TTS provider），随后一轮「MVP 压缩」删掉了
角色推断、引用图与 HTML 视图。但压缩后的形态仍然过重：约 1.7 万行 TypeScript、
五千余行规划文档、九份 ADR——服务的是**一个只有一个工具的 DSH 插件**。

回头审这条线时，判据收敛成一句话：

> **程序只做 agent 干不了的事。** agent 有 bash 与眼睛 —— 列目录、读文件、数数字、
> 判断什么重要，它自己来；程序只做确定性的重活：契约校验、TTS 合成、逐帧渲染、
> 二进制格式的转换。

## 删掉的

| 删掉 | 理由 |
|---|---|
| **分析器**（`foldercast.json` 整个中间产物） | 它产出的「机械事实」（路径 / 类别 / 行数 / 预览 / 审计）全部是 agent 用 `rg --files`、`wc`、`head` 三个命令就能自己拿到的东西。skill 原本就要求 agent 通读内容，digest 并没有省掉通读 |
| **独立素材阶段**（全量转换 + manifest + 回填解读） | 改成**按需**：讲稿引用什么就转换什么（缩略图 / 封面 / 逐页图），按 mtime 缓存在 `assets/cache.json`。讲稿就是清单 |
| **独立校验阶段** | 并进渲染入口（`render --check`）：schema、场景字段、路径存在、字幕切分，有 blocker 退出 2，不进入渲染 |
| **风格预设系统**（四套 × 31 token + overrides + 自然语言映射） | 一套硬编码 token（`renderer/styles.ts`）。没看到真实成片之前，「可换风格」只是给判断增加面 |
| **多 TTS provider**（mimo + 凭据 seam + 密钥引导） | 只留 macOS 自带的 `say`（本地、免密钥）。要云端音色是未来的真需求，不是默认复杂度 |
| **工具里的产物新鲜度报告**（artifacts / missing / stale / fresh） | agent 有 bash，自己会 `stat`。工具不替模型判断下一步 |
| **规划文档五件套、九份 ADR、两份 rd、INTEGRATION 规范** | 零真实使用下写成的决策体系，每次改动要同步八个文档。保留本记录与 README；旧文档在 git 历史里 |

## 留下的（真机械，躲不开）

- **渲染器**：Remotion 组合、八种场景版式、字幕由渲染层绘制（本机 ffmpeg 无 libass）、
  同一讲稿两次渲染逐帧一致、图片内联成 data URI（浏览器读不了 `file://`）。
- **配音**：`say` 合成 → `ffprobe` 实测时长 → 字幕对齐 → 整条音轨。实测与字数预估差
  20–25%，这层省不掉。
- **素材转换本体**：Office/PDF 起引擎转页图（dsoffice）、文本提取（officeparser）、
  视频封面（ffmpeg）、图片缩放（sips）。真依赖、真失败模式，值得固定代码。
- **讲稿契约**：`script.json` 是自足的 —— 结构、盘点、摘录都在讲稿里，引用的文件用
  相对源目录的路径（只有这一种基准）。schema 在 `docs/specs/script.schema.json`。
- **skill**：五步工作流（探目录 → 定场景 → 写稿 → 校验 → 评审）+ 六条评审判据 +
  独立 subagent 评审。对 agent 插件来说，skill 就是产品。

## 形态

```
Agent（有 bash）：rg --files → 挑重点读 → 数数字 → 写 script.json
一个工具：校验（--check）→（显式要求）say 配音 → 按需转换素材 → Remotion 出片
```

配置面：**除了指向哪个目录，没有任何输入。** 风格、provider、筛选、详略档位都
不暴露；真需求出现一个，再暴露一个。
