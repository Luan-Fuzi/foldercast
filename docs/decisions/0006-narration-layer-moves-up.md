# 0006 · 叙事层下移给 Agent 集群，分析器只出事实

- 状态：已接受
- 日期：2026-10-04
- 决策者：项目作者

## 背景

SYSTEM-DESIGN.md 原本规定「分析器不调用模型」，理由是三条：模型会漏文件/编造、结果不可复现、目录内容进模型上下文（隐私 + token 成本）。

但设计过程中暴露出一个**循环依赖**：

```
写稿需要"这个目录在讲什么"
   → 需要内容层的语义
   → 但模型只看到 stats + manifest 摘要
   → 摘要里只有"74 个 TS 文件、最大 2048 字节"
   → 于是只能写出"这个目录有三个部分，第一部分是源码"
```

对**代码项目**这还能凑合（README 提供了语义起点）。对**混杂资料目录**则完全失效——而容器型目录恰恰是 R2 的核心场景（`/Users/scliang/work` 这类工作区）。

作者的决定：

> 「混杂目录有可能本身就是难点，所以我觉得不必因为担心做不好就不去做。我们应该通过 Agent 集群或者某些方式通读这些文件，试图寻找出这些错综复杂的联系，这本来就是这个项目的一部分功能。」

同时明确定义了「理解」的判据：

> 「只要我理解了当前目录的结构，包括文件之间的引用依赖以及整体的知识压缩品，那么我们不管是把它生成 HTML 的讲解 poster，还是生成讲解的视频，其实都是顺带的事情。」

## 决策

**把管线分成两层，性质不同，作者不同。**

| 层 | 谁做 | 输入 | 输出 | 确定性 |
|---|---|---|---|---|
| 事实层 | 程序（analyzer） | 目录本身 | `sources` / `stats` / `manifest` / 引用关系 | 可复现 |
| 叙事层 | Agent 集群 | 事实层产物 **+ 文件内容** | 讲稿（`scenes`） | 不可复现 |

**「分析器不调用模型」继续成立。** 变更的是叙事层的输入范围：从「只能看摘要」放宽为「可以通读文件内容」。

**同时确认「理解」的范围**：不只是结构和分类统计，还包括**文件之间的引用依赖**，以及从中得出的**知识压缩**。

## 理由

1. **循环依赖必须打破。** 摘要里没有语义，就不能要求输出有语义的讲稿。要么放宽叙事层的输入，要么承认讲稿只能停留在宏观描述——作者选择了前者。

2. **两类工作性质本来不同。** 遍历、分类、计数是确定的，程序做；「这些文件合起来在讲什么」是判断，模型做。把两者塞进同一层，要么程序被逼着做判断（不可靠），要么模型被逼着做统计（会漏会编）。

3. **Agent 集群是唯一能"通读"的手段。** 一个有 200 个文件的目录，单次调用读不完。并行 subagent 可以分工读、各自汇报，再由主 agent 汇总。这不是优化，是唯一可行形态。

4. **可复现性没有丢，只是换了位置。** 事实层仍然逐字节可复现——同一目录、同一排除规则，`stats` 与 `manifest` 必然一致。不可复现的只有讲稿，而讲稿本来就是创作产物（[ADR 0002](0002-json-as-intermediate.md) 已经这样定性）。

## 后果

**正面**：

- 混杂资料目录有了可行的处理路径
- 讲稿可以引用具体内容，不再只能讲"有几个文件"
- 「理解」成为一等产物，视频与 poster 都是它的视图
- 事实层与叙事层可分别测试：事实层用 fixture 目录断言输出，叙事层用人工评审判定质量

**负面 —— 必须正视**：

- **可验证性下降。** 「讲的内容确实来自这个目录」原来靠"模型只看到摘要"来保证，现在要改成"讲稿里的每个路径都能在 manifest 里找到"这种事后校验。校验只能挡住幻觉路径，挡不住"讲错了重点"。
- **叙事质量没有指标。** 事实层可以断言"分类无错判"，叙事层没有对应的判据。这是当前最大的空白。
- **token 成本上升。** 读内容比读摘要贵一到两个数量级，大目录尤其明显。
- **隐私承诺作废。** 见下。

**隐私**：`PRODUCT.md` 原本承诺「本地工具，内容不出机器」，`SYSTEM-DESIGN.md` 写着「模型只看 stats + manifest 的摘要」。本决策**推翻**这两条——叙事层会把文件内容送进模型上下文。

作者的判断是这条不必回避：

> 「我觉得没必要追求隐私。我们这个项目就是 DSH 插件，用 AI 默认就是会把这些东西都传给 AI 提供商的，所以没问题。」

**因此分析器不调用模型的理由收窄为两条**：可复现、成本可控。**不再是隐私。**

**缓解**：

- 讲稿生成后校验路径是否存在于 `manifest`，幻觉路径拦截（[ROADMAP.md](../ROADMAP.md) M3 是专门做这件事的里程碑）
- 保留「只读摘要」模式作为降级路径：大目录或用户显式要求时，叙事层退回摘要
- 读内容的范围受 `maxFiles` / `maxFileSizeMb` 约束，不无条件全读

## 备选方案

| 方案 | 否决理由 |
|---|---|
| 维持原状（模型只看摘要） | 混杂资料目录讲不出内容，等于放弃 R2 的核心场景 |
| 分析器内直接调用模型做语义标注 | 让确定性模块变成不可复现模块；且单次调用读不完大目录 |
| 用 embedding / 向量检索代替通读 | 检索解决"找到相关文件"，解决不了"这些文件合起来在讲什么"；且引入向量库依赖 |
| 每次都全量通读 | token 成本不可控；且 `maxFiles` 的存在说明规模必须设限 |
