# 0010 · 创作沟通与内容预算偏好

日期：2026-10-11　状态：已实施　关联：0004、0008、0009

用户希望根据受众、目录内容与讲述重点决定范围和时长，同时能够在设置页手动调整。文件数、代码行数与粗略时长档位只提供参考，不应限制模型的理解与创作。Agent 应利用已有上下文，询问会影响取舍的缺项。

## 决定

新增 `creative` 设置组：沟通方式、默认受众、讲述重点、讲述深度、视频目标分钟数、导览页目标阅读分钟数与创作沟通提示词。设置页首先展示沟通方式、受众和重点，其余内容折叠在「深度、时长与提示词」中。原美术设置单独保留。

沟通方式提供「按需询问」（默认）、「先沟通目标」与「直接规划」。主 skill 要求先利用用户当前要求、已有回答和设置值。按需询问只问会影响内容取舍的缺项；先沟通目标先给目录初步判断和推荐范围，再讨论未明确的目标；直接规划采用可合理推断的偏好并说明假设，只追问影响正确性的缺项。通常一批询问 1–3 个重要问题，并给出推荐选项及其影响，不强制执行固定问卷。

`foldercast_cast` 在有无讲稿时都返回 `creativePreferences`，包含默认沟通方式和深度，以及有效的可选值。设置解析支持 volatile 引用；分钟数允许小数，必须有限且不少于 0.01，留空自动规划。前端提供对应的输入提示并阻止保存无效分钟数。

这些偏好由模型理解，设置中的分钟数不直接传给执行程序。模型结合受众、核心概念、模块关系和重点决定本次内容预算，需要调整默认值时说明理由。文件数、有效代码行数和文档量只说明规模，不机械换算时长。采用的偏好、预算依据与省略范围记入既有的 `digest.notes`，不增加讲稿 schema 版本。

只有模型决定采用的视频目标才换算为秒写入既有的 `video.targetDurationSec`。它仍是软目标；配音后时间轴以实测音频为准。若用户明确要求硬时限，应通过调整讲稿、重新评审和配音验证满足要求，不能截断音频或省略支撑结论必需的事实。

## 边界

导览页目标是预期阅读量，不是播放时长或实际阅读计时。当前页面与视频共享场景，不会自动生成两份不同长度的内容。目标不一致时，Agent 应说明并讨论展开程度的取舍。设置变化不会自动改写已有讲稿。

本次提供设置与工具契约、沟通指导，不增加按照目录规模强制分配时长的算法。Agent 的实际选材与提问质量仍需通过对话和独立评审确认。

## 本机验证

构建分发入口并重启 DeepSeek Harness 后，在真实设置页确认了新分组、折叠区与沟通方式选项。选择「先沟通目标」、输入小数 5.5 分钟与自定义沟通提示词后，覆盖状态和保存状态正常；输入 -1 分钟会显示错误并禁用保存。全部临时值已恢复，保存按钮重新禁用，未保存用户配置。

配置与工具回归覆盖 volatile 活值读取、无效分钟数过滤、默认偏好返回，以及写稿前读取偏好不触发页面、配音或视频产出。实际模型提问与内容取舍未做对话端到端验证。

`pnpm typecheck`、`pnpm run check` 和分发构建通过。全量 `pnpm test` 通过：32 个测试文件，288 项通过、2 项跳过，包含真实浏览器渲染与本机画面基线比较。
