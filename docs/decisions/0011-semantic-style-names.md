# 0011 · 设计名称共用于设置、创作指导与讲稿

日期：2026-10-11　状态：已实施　关联：0009、0010

用户要求风格名称直接表达设计含义，并进入 AI 的创作提示词。「素稿」是内部称呼，「杂志」「夜幕」分别偏向载体与氛围，无法清楚表达所选设计方向。仅在界面改标签、仍让模型读取旧标识不能满足要求。

## 决定

对外名称统一为「瑞士风格」「编辑设计风格」「科技风格」，分别附英文术语 `Swiss Style / International Typographic Style`、`Editorial Design`、`Tech-inspired Design`。设置页选项、新讲稿与工具返回均使用这些名称。

「瑞士风格」与 `International Typographic Style` 的同义关系有明确的设计史依据，见[瑞士国家图书馆](https://www.nb.admin.ch/en/the-international-style-1950-1970)。「编辑设计」是设计领域，见 [Adobe 对 editorial and layout design 的介绍](https://blog.adobe.com/en/publish/2018/06/25/holy-crop-editorial-layout-design-week)；本项目将其作为设计方向。「科技风格」也是宽泛设计方向，不声称三者都是同一层级、具有统一规范的历史流派。

共用风格定义新增英文名称与内置创作指导。`foldercast_cast` 返回的 `visualPreferences` 包含 `style`、`stylePrompt` 和可选的用户补充 `prompt`。内置指导带上风格名称与设计术语，说明内容组织、排版与素材选择的方向；模型结合用户本次要求采用，可调整，不直接由程序执行。设置页可展开查看同一段指导，避免界面说明与模型收到的内容分离。

主 skill 要求新讲稿的 `script.visual.style` 使用对外设计名称，`script.visual.prompt` 记录本次采用的美术指导，包含名称、需保留的原则、用户补充和创作取舍。已有讲稿不会因设置变化被自动改写。

## 兼容

旧名称「素稿 / 杂志 / 夜幕」只保留为输入别名，分别归一到三个新名称。配置 schema 和讲稿 schema 继续接受旧值，设置页显示与工具输出使用新名称。归一发生在使用处，不修改旧讲稿文件或加载后的原始内容，保留其哈希与现有评审版本语义。

CLI 接受新名称和旧别名，产物报告与实际设置记录使用新名称。重命名不改变现有色板、字体、卡片参数和页面补充样式。视频与页面仍使用现有模板，不把命名或创作指导当作已经实现全部设计原则的保证。

## 边界

本次不增加用户自建风格注册表或密钥配置入口，也不变更配音读取方式。自定义美术提示词仍作为用户补充保留。

## 验证

类型检查、文档与示例检查、分发构建通过。相关 74 项测试通过，覆盖新旧名称的渲染参数一致性、真实 schema 接受两类讲稿且不修改原内容、工具返回具名创作指导，以及页面入口按旧名称执行并报告新名称。另用真实渲染 CLI 分别传入六个新旧名称执行 `--check`，均成功；本次未重跑完整视频渲染。

本机 Harness 当前存在未保存的配音设置，保留其草稿，没有重启应用。新的客户端与插件入口已构建，需下次重启后加载；本次未做新界面的实际目检。
