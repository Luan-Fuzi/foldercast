# 风格预设系统

对应需求维度 3：**预设几种艺术风格，同时允许用户用自然语言描述自己的风格**。

---

## 一、设计目标

1. **预设要好用**：选一个名字就能出片，不需要理解 token。
2. **能自由覆盖**：想改一个颜色就改一个颜色，不用 fork 预设。
3. **自然语言能落地**：写"深蓝背景、衬线标题、节奏慢一点"就能生效。
4. **风格必须影响两件事，不只是颜色**：视觉（怎么画）+ 叙事（怎么讲）。
5. **渲染阶段不调用模型**：自然语言解析发生在写稿阶段，结果固化进 JSON。

---

## 二、为什么风格要包含「叙事语气」

这是本设计最关键的一点。同一份目录，用不同的语气讲，产出的讲稿完全不同：

- **讲解型**：「这个目录分成三个部分。第一部分是源码，包含……」
- **导览型**：「跟着我走一遍。先看入口，再看它调用了什么……」
- **汇报型**：「本目录共 128 个文件，其中代码 74 个，占比 58%。」

选择「瑞士风格」如果只改了配色，讲稿还是同一份，那风格就是半成品。**所以 `style.narration` 必须参与写稿提示词，而不是只影响渲染。**

## 三、Token 定义

四组，共约 30 个 token。全部扁平命名，便于覆盖和校验。

### 3.1 画布 `canvas.*`

| token | 类型 | 说明 |
|---|---|---|
| `canvas.aspect` | enum | `16:9` / `9:16` / `1:1` / `4:3` |
| `canvas.width` / `canvas.height` | int | 分辨率，未指定时由 aspect 推导（1080p 基准） |
| `canvas.safeMargin` | int | 内容区距边缘像素 |

### 3.2 配色 `palette.*`

语义命名，不叫 `color1/color2`，这样换预设时组件不需要改。

| token | 角色 |
|---|---|
| `palette.bg` | 背景 |
| `palette.ink` | 主文字 |
| `palette.muted` | 次级文字 |
| `palette.line` | 分隔线、边框 |
| `palette.accent` | 强调色（**唯一**的强调色，克制使用） |
| `palette.panel` | 卡片/面板底色 |
| `palette.codeBg` | 代码块底色 |

### 3.3 字体 `typography.*`

| token | 说明 |
|---|---|
| `typography.title` | 标题字体族 |
| `typography.body` | 正文字体族 |
| `typography.mono` | 等宽字体族 |
| `typography.titleWeight` | 标题字重 |
| `typography.scale` | 字号比例：`compact` / `normal` / `airy` |

### 3.4 版式 `layout.*`

| token | 说明 |
|---|---|
| `layout.density` | `compact` / `normal` / `airy`，控制信息密度 |
| `layout.rule` | 是否用分隔线：`none` / `hairline` / `bold` |
| `layout.numbering` | 章节编号样式：`none` / `decimal` / `roman` |
| `layout.header` | 页眉：`none` / `title` / `chapter-progress` |

### 3.5 动效 `motion.*`

| token | 说明 |
|---|---|
| `motion.pace` | `slow` / `normal` / `fast` |
| `motion.in` | 入场方式：`fade` / `slide` / `type` / `none` |
| `motion.easing` | 缓动曲线名 |
| `motion.transition` | 场景间转场：`cut` / `fade` / `wipe` |

### 3.6 质感 `texture.*`

| token | 说明 |
|---|---|
| `texture.grain` | 噪点强度 0–1（纸质感） |
| `texture.shadow` | 阴影：`none` / `soft` / `hard` |
| `texture.radius` | 圆角半径像素 |

### 3.7 叙事 `narration.*` ← 参与写稿

| token | 说明 |
|---|---|
| `narration.tone` | `expository` 讲解 / `tour` 导览 / `report` 汇报 |
| `narration.person` | `second` 你 / `first-plural` 我们 / `neutral` |
| `narration.density` | `concise` / `normal` / `detailed` |
| `narration.opening` | 开场策略：`question` / `summary` / `context` |

## 五、自然语言 → Token 的映射

### 流程

```
用户写："深蓝背景，标题用衬线体，节奏慢一点"
        │
        │  ① 写稿阶段：模型解析
        ▼
{ "palette.bg": "#0B1B2B", "typography.title": "serif", "motion.pace": "slow" }
        │
        │  ② 校验：token 名存在？值类型/枚举合法？
        ▼
        │  ③ 应用到预设之上，结果固化
        ▼
style.overrides  ← 渲染阶段只读这里，不再调用模型
```

### 三条约束

1. **只允许覆盖已存在的 token。** 模型不能发明新 token。遇到无法映射的描述（如"让它更高级一点"），写进 `style.unresolved` 并提示用户，不静默丢弃。
2. **枚举值必须落在白名单内。** `motion.pace` 只能是 `slow`/`normal`/`fast`，模型给 `slower` 要报错而不是猜。
3. **解析结果必须回写。** 渲染是确定性的，不能依赖一次模型调用。同一份 JSON 渲染两次必须得到相同结果。

### 常见描述的映射表

| 用户说法 | 映射 |
|---|---|
| 深色 / 暗色 / 黑底 | `palette.bg` → 深色系 |
| 亮一点 / 白底 | `palette.bg` → 浅色系 |
| 衬线 / 宋体 / 有书卷气 | `typography.title/body` → serif 链 |
| 等宽 / 代码感 / 极客 | `typography.*` → mono |
| 节奏慢 / 从容 / 舒缓 | `motion.pace` → `slow` |
| 紧凑 / 信息多 / 干货 | `layout.density` → `compact`，`typography.scale` → `compact` |
| 留白多 / 透气 / 高级 | `layout.density` → `airy`，`canvas.safeMargin` → 加大 |
| 圆角 / 柔和 | `texture.radius` → 8–16 |
| 直角 / 硬朗 / 极简 | `texture.radius` → 0，`texture.shadow` → `none` |
| 纸感 / 复古 | `texture.grain` → 0.05+，配色转暖 |
| 圆角卡片 / 面板感 | `texture.radius` + `palette.panel` |
| 竖版 / 手机 | `canvas.aspect` → `9:16` |
| 讲得细一点 | `narration.density` → `detailed` |
| 别啰嗦 / 直接说结论 | `narration.density` → `concise`，`narration.opening` → `summary` |

## 六、预设的存放与扩展

`styles/*.json`，一个预设一个文件：

```
styles/
  swiss.json
  deck.json
  console.json
  paper.json
```

- 内置四套随包分发
- 用户可在 `~/.config/foldercast/styles/` 放自己的预设
- `foldercast.json` 里 `style.preset` 可以是内置名，也可以是文件路径
- 预设之间支持 `extends`：`"extends": "swiss"` 后只写差异
