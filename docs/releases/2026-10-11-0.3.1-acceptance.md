## 安装与宿主加载

1. 全新 profile 从 npm 安装 `dsh-foldercast@0.3.1-rc.1`，首次返回 `ERR_PNPM_IGNORED_BUILDS`，列出 esbuild、koffi、msedge-tts、tesseract.js。在该测试 profile 批准四项构建后，安装能完成；此次没有复现先前的下载错误 (23)。
2. 自动化调用保留标准输入时，pnpm 已输出完成信息，但进程未退出。单独用系统 Node 和宿主 Node 运行同一 pnpm 均能退出；原 DSH 安装命令关闭标准输入后也能退出。本次后续自动化统一关闭标准输入，没有更改插件代码或宿主文件。
3. 发现宿主恢复问题：首次失败已写入 `dependencies`，成功重试后 `dsh.profile.bundles` 仍缺少 `dsh-foldercast`，因此 schema 没有插件条目。宿主的安装协调代码只为新依赖添加 bundle，符合该现象。在本次首次安装尚未使用的测试 profile 中移除后重装，bundle 列表和插件 schema 均恢复。[使用说明](../usage.md)已补充适用条件与命令。
4. `acceptance-ui` 在首次安装前已允许相同四项构建，安装直接成功；bundle 列表包含 `dsh-foldercast`，宿主加载其配置 schema，网页服务实际启动成功。
5. `web` 模板自身导出完整 schema 时因 Loader carrier 不支持而退出 1；安装插件前后都有此错误。插件条目存在不能改写为完整 schema 导出通过。仅 base 模板导出成功。
