# 0.3.1 候选版检查

版本：0.3.1-rc.1。状态：准备候选版；未发布正式 0.3.1。实施依据为[发布计划](../plans/0.3.1-release.md)，检查起点为 `c334631`。

## 代码与契约

- 共用源引用检查覆盖讲稿、digest、revision、素材准备与图片读取。11 个边界用例先复现 10 项失败；修复后通过。包括绝对路径、目录穿越、目录外链接与根目录链接别名。
- 新增协作锁，拒绝同目录的独立执行；插件向阶段进程传递锁上下文。任务正常结束或失败时释放。SIGKILL 或主机断电后的残留锁需确认所属进程结束后清理；没有实现排队调度。
- 阶段运行器限制输出内存，过量 JSON 明确失败；取消和超时清理子进程与其独立进程组，并升级终止。真实后代进程测试使用独立进程组且忽略 SIGTERM，验证取消后停止写入；实际渲染取消时，已启动浏览器，记录的 2 个阶段／浏览器进程全部结束。
- tree 的 `path` 现核对真实路径；原夹具的 `(根目录)` 改为 `.`。自定义输出避开被引用目录，留在 `.foldercast/` 下。

## HTML

- 自动页脚不再包含本机源目录；根据实际图片内联情况说明转发依赖。
- 实际 Chrome 检查原 showcase 讲稿：320、390、768、1440px 下整页宽度等于视口，导航锚点无缺失。高亮器的内联 `overflow: visible` 是原 418px 溢出的直接原因；页面通过区块内横向滚动处理代码。
- 新增浏览器回归用例覆盖长标题、对比和长代码。示例只重做 HTML 排版，清单区分新的页面渲染版本与原 0.3.0 视频、评审和 revision。
