# 发布候选检查 · 2026-10-11

本报告记录 0.3.0 的发布前检查。检查范围：`2b450a3` 之后的工作区改动与新增文件。功能依据为本次用户讨论及决策 0009–0012；规范依据为项目 `AGENTS.md`。包版本按用户决定设为 `0.3.0`。

## Standards

发现并修复 1 项维护性问题，未发现新增的项目硬规范违规：

- 默认瑞士风格的视频参数绕过共享预设，字体与 HTML 定义不同，修改共享预设无法同步到默认视频。所有视频预设现从同一入口投影。旧视频字体栈移入共享瑞士定义，保留默认视频表现，瑞士风格 HTML 也使用该字体栈；测试覆盖三套预设的字体一致性。

## Spec

发现并修复 1 项设置页实现错误及 2 项既有缺口：

- 切换配音引擎和选择默认音色时，宿主普通文本字段把空串解释为删除覆盖，可能恢复另一引擎的继承音色。音色字段现保存显式空串；「恢复默认」仍删除覆盖。用真实 Harness 表单模型和模拟配置层验证了两种操作。
- 文档约定读取被讲解目录的 `.env`，但 CLI 未传项目目录。配音入口现传入 `projectRoot`，离线 CLI 检查确认会读取项目密钥且不输出密钥。
- 并发配置允许小数，保存后却被解析层丢弃。配置 schema 和设置页现共同要求 1–8 的整数；分钟预算继续允许小数。

其余检查范围未发现明确的需求缺失或超范围实现：风格名称与指导一致，自定义风格不附加基础预设的创作原则，预算交给模型规划，已有上下文和当前要求优先，旧名称兼容与 HTML-only 工作流保留。
